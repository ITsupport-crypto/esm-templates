# Formal ESM Reply Templates | نماذج الردود الرسمية على تذاكر نظام ESM

> **Usage Guide:** Replace all `<placeholders>` with the relevant information before sending. These templates are designed for use within a ticketing tool. Do not include subject lines or signature blocks.
>
> **دليل الاستخدام:** يُرجى استبدال جميع `<المتغيرات>` بالمعلومات المناسبة قبل الإرسال. هذه النماذج مخصصة للاستخدام داخل نظام التذاكر. لا تُضف سطر موضوع أو توقيع.

## Placeholders Reference | مرجع المتغيرات

| English Placeholder               | Arabic Placeholder               | Description / الوصف                        |
|-----------------------------------|----------------------------------|--------------------------------------------|
| `<User>`                          | `<اسم المستخدم>`                 | Customer's name / اسم العميل               |
| `<Date>`                          | `<التاريخ>`                      | Date of call or meeting / تاريخ المكالمة   |
| `<X business days>`               | `<X أيام عمل>`                   | SLA / response period / مدة الاستجابة      |
| `<System/Portal Name>`            | `<اسم النظام / البوابة>`         | Target application / التطبيق المستهدف      |
| `<Correct Service Offering Name>` | `<اسم عرض الخدمة الصحيح>`        | Right service category / فئة الخدمة الصحيحة |
| `<Correct Request Type>`          | `<نوع الطلب الصحيح>`             | Right request type / نوع الطلب الصحيح      |
| `<Team/Recipient Name>`           | `<اسم الفريق / المستلم>`         | Target support team / فريق الدعم المستهدف  |
| `<Third Party Team/Vendor>`       | `<الفريق / المورّد / القسم>`     | External team or vendor / الطرف الخارجي    |
| `<Existing Ticket ID>`            | `<رقم التذكرة الموجودة>`         | Duplicate ticket reference / رقم التذكرة  |
| `<Start Time>` / `<End Time>`     | `<وقت البدء>` / `<وقت الانتهاء>` | Maintenance window / نافذة الصيانة         |
